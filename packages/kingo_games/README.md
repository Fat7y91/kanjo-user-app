# Kingo Games

Local Flutter package for Kingo mini-games.

## Games

- **Flying Bird** — `FlyingBirdGameView`
- **Gun Shooter** — `GunShooterGameView`
- **Arena Survival** — `ArenaSurvivalGameView`

## Adding a new game

1. Create `lib/src/<game_name>/`
2. Export it from `lib/kingo_games.dart`
3. Use it from the app via `package:kingo_games/kingo_games.dart`
